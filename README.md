# Compiler Optimization Study

![CI](https://github.com/atsa111/compiler-optimization-study/actions/workflows/ci.yml/badge.svg)

Учебная практика по теме:

**«Сравнение и анализ оптимизаций компиляторов»**

## Цель работы

Цель проекта — исследовать влияние оптимизаций различных компиляторов языка C на:

- генерируемый ассемблерный код;
- размер исполняемого файла;
- размер секции `.text`;
- время выполнения;
- структуру машинных инструкций;
- эффективность оптимизаций по скорости и размеру.

## Исследуемые компиляторы

| Компилятор | Версия | Роль |
|---|---:|---|
| GCC | 13.3.0 | основной |
| Clang | 18.1.3 | дополнительный |
