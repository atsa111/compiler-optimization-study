# v1.0.0

Первый стабильный релиз проекта
«Сравнение и анализ оптимизаций компиляторов».

## Добавлено

- сравнение GCC, Clang и TCC;
- исследование уровней оптимизации `-O0`, `-O1`, `-O2`, `-O3`, `-Os`;
- генерация ассемблерного кода;
- сравнение размеров исполняемых файлов;
- анализ размера секции `.text`;
- автоматические benchmark-скрипты;
- фиксация характеристик экспериментальной системы;
- тесты сборки и запуска;
- ShellCheck и cppcheck;
- GitHub Actions CI;
- Dependabot;
- документация учебной практики;
- результаты экспериментов.
